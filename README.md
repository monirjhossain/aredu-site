# ChinaEdu Frontend Clone (Vue 3)

Pixel-faithful Vue.js frontend clone of [cnedubd.com](https://cnedubd.com/) — logo excluded (text brand only).

## Stack
- Vue 3 + Vite
- Vue Router
- Tailwind CSS 3
- Tabler Icons

## Run
```bash
cd frontend
npm install
npm run dev
```

## Structure
```
src/
  components/layout/   # Header, Footer, Mega menus, Mobile drawer
  components/ui/       # Shared cards, FAQ, counters
  data/                # Site constants + JSON datasets
  pages/               # All routes (home, listings, tools, details)
  router/              # Vue Router
  styles/              # Global CSS + brand tokens
```
